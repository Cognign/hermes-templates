# Hermes templates

Starter apps that the Hermes assistant copies into a new app and then extends.

Hermes pins this repository as a git submodule at a reviewed commit and ships the templates inside its images. Nothing downloads this repository at runtime. Apps keep the files they copied, so a change here does not update existing apps.

Templates arrive in follow-up pull requests.
